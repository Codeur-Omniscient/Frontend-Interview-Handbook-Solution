# Frontend Interview Questions - Solutions

Ce dépôt contient les solutions à neuf questions d'entretien techniques fréquemment posées lors d'interviews pour des postes de développeur frontend, provenant de la plateforme Frontend Handbook.

## Structure du projet

Chaque question d'entretien est organisée dans son propre dossier, contenant un fichier `solution.md` qui présente :

- L'énoncé complet de la question
- Une description détaillée du problème
- Des exemples de code illustrant l'utilisation attendue
- Une solution implémentée et commentée

```md
├── README.md
├── Debounce/
│ └── solution.md
├── PromiseAll/
│ └── solution.md
├── Flatten/
│ └── solution.md
└── ...
```
